# Pa'dentro Buffet y Cantina · Menú digital

React + Vite + TypeScript. Carta completa (251 productos), carrito y pedido por WhatsApp.

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción (dist/)
```

**Fotos:** coloca archivos en `public/images/` — `hero.jpg`, `casa.jpg`, `fav-mole.jpg`, `fav-nogada.jpg`, `fav-carajillo.jpg`, `galeria-1.jpg` … `galeria-5.jpg`. Si no existen se muestra un fondo de marca.

**Datos:** negocio y redes en `src/config.ts`; carta y precios en `src/menu.json`.

**Deploy:** sube a GitHub e importa el repo en Vercel (framework: Vite, build `npm run build`, output `dist`).
